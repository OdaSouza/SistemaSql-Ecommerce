# SistemaSql-Ecommerce
Script para criação de banco de dados para a linguagem MySql.

## Sumário

 - Este script é utilizado apenas para a criação do banco de dados e não possui outro próposito além de criar o sistema sem adição de dados ou normalização.
 - O esquema está na no arquivo de PDF.
 - O script "Inserção_e_Normalização_Nodel_Oda" insere dados e faz analise para verificar alguns dados ali inseridos como a quantidade de pedidos feitas.

## Tecnologias Usadas

Linguagem: MySQL
SGBD Usado: MySql Workbanch 8.0
